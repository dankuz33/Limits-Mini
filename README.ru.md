# Limits Mini

[English](README.md) · **Русский**

**Лимиты Claude Code и Codex в компактном виджете для Windows.**

Два сервиса, две строки, только нужные цифры. Limits Mini показывает использование лимитов на рабочем столе и в системном трее, чтобы не приходилось постоянно открывать страницы аккаунтов.

## Зачем я это сделал

Я пользуюсь Claude Code и Codex для разработки и хотел держать их лимиты перед глазами. Не в отдельном дашборде, не в большой панели поверх рабочего пространства, а в небольшом виджете: иконка сервиса, текущий расход и недельный лимит.

Референсом стал компактный интерфейс приложения для macOS. Среди рассмотренных Windows-решений я не нашёл того сочетания внешнего вида и простоты, которое мне хотелось, поэтому решил сделать свою утилиту.

Проект разрабатывался с помощью ИИ и проверялся на моём Windows-компьютере. После первого запуска я доработал иконки, убрал лишнюю ширину, сделал оформление аккуратнее и разобрался с подключением аккаунтов. Главная сложность оказалась не в отрисовке процентов, а в том, чтобы правильно получить данные: открытого Claude Desktop недостаточно для этой интеграции, а CLI в моей сетевой конфигурации потребовал явной настройки HTTP-прокси.

В результате получилась небольшая утилита для повседневной работы, а не ещё один интерфейс, за которым нужно следить.

## Что умеет

- Показывает Claude Code и Codex в одном компактном виджете и отдельными цифровыми значками в трее.
- Отображает доступные окна лимитов, время сброса и состояние подключения.
- Позволяет переключаться между использованным процентом и остатком.
- Поддерживает перетаскивание, сохранение позиции, масштаб и режим поверх окон.
- Может работать только в трее; обновляет данные автоматически, умеет запускаться вместе с Windows.

По умолчанию обновление выполняется каждые 5 минут. В меню доступны интервалы 1, 3, 5 и 10 минут, а также ручное обновление.

Это обычное отдельное приложение Windows с компактным окном, а не расширение системной панели «Виджеты». Интерфейс версии 0.2.0 на русском языке.

## Как читать цифры

```text
Claude   24 / 3%
Codex      100%
```

При настройке по умолчанию `24 / 3%` означает 24% использованного текущего 5-часового окна Claude и 3% недельного лимита.

В строке Codex показан основной доступный лимит. Когда сервис возвращает только недельное окно, цифра относится именно к нему. `100%` использовано соответствует `0%` остатка. Тип окна и время сброса можно посмотреть в подробностях.

Значения на скриншоте приведены как пример, а не как ожидаемые цифры после установки. Состав доступных лимитов зависит от ответа сервиса. `--` означает отсутствие актуального значения, а не нулевой расход.

## Установка

1. Скачайте ZIP-архив сборки Limits Mini из раздела **Releases** этого репозитория, а не архив **Source code**.
2. Полностью распакуйте его и запустите `Установить.cmd`.
3. Закройте сообщение об установке. Программа запустится; ярлыки появятся на рабочем столе и в меню «Пуск».

Права администратора и отдельная установка Go, Python, Node.js или .NET для самой утилиты не нужны. Клиенты Claude Code и Codex подключаются отдельно.

Можно запустить `LimitsMini.exe` непосредственно из распакованной папки без установки. Настройки при этом всё равно сохраняются в профиле Windows, а не рядом с EXE.

Автозапуск по умолчанию выключен. Включить его можно через правую кнопку мыши по виджету. Для обновления повторите установку из нового архива. Для удаления: **Пуск → Limits Mini → Uninstall Limits Mini**.

## Подключение аккаунтов

**Claude:** нужен вход по подписке через Claude Code CLI, установленный непосредственно в Windows. Одного входа в Claude Desktop или браузере для текущей реализации недостаточно. Утилита использует локальную авторизацию CLI и не извлекает cookies из Desktop.

[Пошаговая инструкция подключения Claude](docs/claude-setup.ru.md), включая установку CLI, вход и настройку прокси при необходимости.

**Codex:** установите Codex и войдите в аккаунт ChatGPT. Limits Mini ищет локальный `codex.exe` и запрашивает лимиты через `codex app-server`. Если автоматический поиск не сработал, выберите **ПКМ → Подключение → Codex: выбрать codex.exe** и укажите исполняемый файл установленного Codex, а не случайный EXE из интернета.

## Управление

Перетащите виджет левой кнопкой мыши, чтобы изменить его положение. Правая кнопка открывает настройки и подключение. Двойной клик по виджету показывает подробные лимиты и время сброса; обычный клик по значку в трее открывает компактное всплывающее окно.

Программа устанавливается в `%LOCALAPPDATA%\LimitsMini`. Настройки находятся в `%LOCALAPPDATA%\LimitsMini\data\settings.json`.

## Как устроено и что с приватностью

Текущая сборка написана на **Go + Win32**, без Electron и сторонних Go-модулей. Это готовый Windows EXE, а не веб-приложение.

Для Claude программа читает локальный OAuth-токен Claude Code и обращается к usage endpoint Anthropic. Основной путь Codex использует локальный app-server и метод `account/rateLimits/read`. Если он недоступен, предусмотрен резервный запрос с токеном из локального `auth.json` к usage endpoint ChatGPT.

У Limits Mini нет собственного сервера, телеметрии и автоматической загрузки обновлений. Программа не сохраняет токены в свои настройки, не читает browser cookies и не перезаписывает файлы авторизации. Запущенный официальный клиент Codex может сам обслуживать свою авторизацию.

Это не означает отсутствия доступа к чувствительным данным: для запросов используются учётные данные аккаунтов. Не публикуйте `.credentials.json`, `auth.json`, OAuth-токены или скриншоты с ними.

## Ограничения

Это ранняя версия с проверкой на отдельной Windows-конфигурации, а не гарантия совместимости со всеми аккаунтами и сетями. Сборка не подписана цифровым сертификатом издателя; происхождение файла следует проверять, а не отключать защиту Windows.

Limits Mini не увеличивает и не обходит лимиты. Он показывает доступные данные сервиса с периодическим обновлением, а не в реальном времени. Интеграция Claude и резервный путь Codex зависят от служебных endpoint, формат и доступность которых могут измениться.

Утилита не обновляет OAuth-токен Claude самостоятельно. Когда он истечёт, может понадобиться открыть Claude Code или повторить вход через `claude auth login`.

Поддерживается статический системный прокси Windows для собственных HTTP-запросов утилиты; PAC-скрипты не обрабатываются. После изменения прокси перезапустите Limits Mini. Запуск авторизации CLI через меню не означает, что CLI автоматически получит системные настройки прокси: для него при необходимости задаются переменные окружения, описанные в инструкции.

Независимый проект, не связанный с Anthropic или OpenAI. Названия сервисов и обозначения используются для их идентификации.
