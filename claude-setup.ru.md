# Подключение Claude к Limits Mini

[English](claude-setup.md) · [Главная](../README.ru.md)

Для версии Limits Mini 0.2.0. Инструкция для Claude Code, установленного непосредственно в Windows, не внутри WSL.

## Что нужно заранее

Нужен аккаунт с доступом к Claude Code по подписке и возможность подключаться к сервисам Anthropic. Вход только в Claude Desktop или браузере для текущей интеграции недостаточен: Limits Mini читает авторизацию Claude Code CLI.

Покупать API-кредиты для виджета не нужно. Вход в Anthropic Console по API-ключу не заменяет вход по подписке для этих счётчиков.

## 1. Установите Claude Code

Откройте обычный **PowerShell**, без запуска от имени администратора, и выполните:

```powershell
winget install --id Anthropic.ClaudeCode --exact
```

Полностью закройте окно терминала, откройте новое и проверьте установку:

```powershell
claude --version
```

Команда должна вывести версию Claude Code. Если `winget` недоступен, используйте другой способ из [официальной инструкции установки](https://code.claude.com/docs/en/setup).

## 2. Войдите в аккаунт Claude

В том же PowerShell выполните:

```powershell
claude auth login
```

Завершите вход в браузере в тот аккаунт, лимиты которого нужно отображать. Если появится выбор способа входа, используйте **Claude account with subscription**, а не **Anthropic Console account**.

Для этой операции не нужно запускать агентную сессию в папке проекта или разрешать доступ к `C:\Windows\System32`. Команда `claude auth login` запускает именно авторизацию.

Проверьте её состояние:

```powershell
claude auth status --text
```

Команда должна сообщить об успешном входе. Не публикуйте её полный вывод без проверки на персональные данные.

Команды входа и проверки описаны в [официальном справочнике CLI](https://code.claude.com/docs/en/cli-reference).

## 3. Обновите виджет

Вернитесь в Limits Mini и выберите **ПКМ → Обновить сейчас**.

Если вместо процентов осталось `--`, откройте **ПКМ → Лимиты и состояние подключения**. Это окно покажет причину: не найден вход, истёк токен, нет сети или сервис отклонил запрос.

При установленном CLI повторный вход также можно запустить через **ПКМ → Подключение → Подключить Claude Code**. В версии 0.2.0 эта кнопка не устанавливает CLI автоматически.

Держать окно Claude Code открытым постоянно не нужно, пока сохранённый access-токен действителен. Limits Mini сам токен не обновляет. При его истечении откройте Claude Code, а если данные не восстановились, повторите `claude auth login` и обновите виджет.

## Когда нужен прокси

Этот раздел нужен только при проблеме соединения, например `Unable to connect to Anthropic services`. Если всё работает, дополнительных настроек не требуется.

Работающий браузер не доказывает, что CLI использует тот же маршрут. Claude Code поддерживает [HTTP_PROXY и HTTPS_PROXY](https://code.claude.com/docs/en/network-config).

Для **локального HTTP-прокси** пример выглядит так:

```powershell
$proxy = "http://127.0.0.1:10809"
$env:HTTP_PROXY = $proxy
$env:HTTPS_PROXY = $proxy
claude auth login
```

`10809` здесь только пример. Подставьте HTTP-порт из настроек своего доверенного прокси-клиента. Клиент должен быть запущен. Не используйте SOCKS-порт в этой инструкции и не отключайте проверку TLS-сертификатов.

Эти команды меняют окружение только текущего PowerShell и запускаемых из него процессов. Они не записывают прокси постоянно в Windows и не меняют уже запущенные программы.

**Для самого Limits Mini:** версия 0.2.0 читает статический системный прокси Windows при запуске. Включите его в своём клиенте и полностью перезапустите Limits Mini. TUN для подключения через явный HTTP-прокси не обязателен; PAC-скрипты текущая версия не обрабатывает.

Другой вариант для установленной утилиты: завершите прежний экземпляр через **ПКМ → Выход**, затем запустите её из того же PowerShell, где заданы переменные:

```powershell
Start-Process "$env:LOCALAPPDATA\LimitsMini\LimitsMini.exe"
```

Так процесс унаследует настройки прокси. Для запуска без установки укажите фактический путь к EXE.

<details>
<summary>Проверка доступности Anthropic через прокси</summary>

В том же PowerShell:

```powershell
curl.exe --proxy $proxy --connect-timeout 10 --max-time 20 --head https://api.anthropic.com
```

Здесь `HTTP/1.1 200 Connection established` может быть ответом самого прокси на создание туннеля. Смотрите также на следующий HTTP-ответ от целевого сервера.

Например, конечный `404 Not Found` при запросе корня сайта подтверждает, что HTTPS-соединение установлено, но не проверяет правильность аккаунта или доступ к usage endpoint. Если соединение истекает по тайм-ауту, сначала нужно восстановить сетевой доступ.

## Частые проблемы

**«Claude Code CLI не найден».** Проверьте `claude --version` в новом терминале. Убедитесь, что установлен именно CLI, а не только Desktop. Перезапустите Limits Mini после установки CLI.

**Вход выполнен, но виджет не видит его.** Проверьте аккаунт и тип входа через `claude auth status --text`. В стандартной Windows-установке авторизация хранится в `%USERPROFILE%\.claude\.credentials.json`. При нестандартном пути используйте **ПКМ → Подключение → Claude: выбрать .credentials.json**. Выберите файл локально, не копируйте его содержимое в чат или Issue. Расположение credentials описано в [документации Anthropic](https://code.claude.com/docs/en/authentication).

**«Токен истёк» или HTTP 401.** Откройте Claude Code; при необходимости выполните `claude auth login`. После завершения входа обновите виджет.

**HTTP 403.** Это отказ сервиса, а не подтверждение одной конкретной причины. Проверьте правильность аккаунта, права доступа и доступность сервиса в вашей сети.

**HTTP 429.** Слишком частые запросы к сервису. Дождитесь окончания паузы, не нажимайте обновление подряд. Эта ошибка сама по себе не означает, что недельный лимит модели исчерпан.

**Проценты отличаются от страницы Usage.** Сравните один аккаунт и одно окно лимита, обновите обе страницы. При включённом режиме «остаток» виджет показывает `100 − использовано`. Данные могут быть получены в разное время.

> Никогда не добавляйте `.credentials.json`, `auth.json` или токены в публичный репозиторий. Не отключайте антивирус или проверку HTTPS ради подключения.
