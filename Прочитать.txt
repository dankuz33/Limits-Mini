LIMITS MINI 0.2.0
Claude Code + Codex | Windows 10/11/11, x64

БЫСТРАЯ УСТАНОВКА

1. Полностью распакуйте архив.
2. Дважды нажмите «Установить.cmd».
3. Если была установлена 0.1.0, установщик сам закроет старую версию и заменит её.
4. После установки появится компактный виджет и ярлык на рабочем столе.

Можно запускать LimitsMini.exe и без установки.
Python, Node.js и .NET для запуска не требуются. Права администратора не нужны.

ВАЖНО ПРО CLAUDE

Claude Desktop и Claude Code используют разные локальные сессии авторизации.
То, что обычное приложение Claude открыто и показывает Usage, не означает,
что сторонняя утилита безопасно может получить OAuth Claude Code.

Limits Mini намеренно НЕ извлекает зашифрованные cookies/token storage Claude Desktop.
Для счётчиков нужен один штатный вход Claude Code:

ПКМ по виджету -> Подключение -> Подключить Claude Code

Откроется официальный `claude auth login`. После успешного входа нажмите
«Обновить сейчас». Обычно это нужно сделать только один раз.

После подключения в вашем текущем примере Claude должен показывать примерно
24/3%: текущая 5-часовая сессия / недельное окно, если API вернёт те же данные,
что отображаются в Usage Claude.

CODEX

Используется локальный Codex app-server и метод account/rateLimits/read.
Если Codex отдаёт только weekly limit, Limits Mini показывает именно его.
100% означает 100% использовано, что соответствует «Остается 0%» на странице Codex.

УПРАВЛЕНИЕ

- Перетащить левой кнопкой: переместить виджет.
- ПКМ: настройки, подключение, обновление, автозапуск.
- Клик по иконке в трее: компактное всплывающее окно.
- Двойной клик по виджету: подробные лимиты и время сброса.
- Можно оставить только трей и скрыть виджет на рабочем столе.
- Можно показывать расход или остаток.
- По умолчанию Claude показывает 5h / week, Codex основной доступный лимит.

БЕЗОПАСНОСТЬ

Утилита не имеет собственного сервера, аналитики и рекламы.
OAuth Claude читается из локального credential store Claude Code только для обращения
к api.anthropic.com. Файл credentials не перезаписывается.
Codex запрашивается через локальный app-server; запасной вариант читает auth.json.
Токены не пишутся в файлы Limits Mini и не отправляются на сторонние домены.
Cookies браузера и зашифрованное хранилище Claude Desktop не читаются.

EXE не подписан коммерческим сертификатом, поэтому Windows может показать
предупреждение об неизвестном издателе. Отключать Defender/антивирус не требуется.

УСТАНОВКА

Программа: %LOCALAPPDATA%\LimitsMini\LimitsMini.exe
Настройки: %LOCALAPPDATA%\LimitsMini\data\settings.json
Удаление: меню «Пуск -> Limits Mini -> Uninstall Limits Mini».
